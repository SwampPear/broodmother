**Procedural reference for filing a U.S. provisional patent application (PPA) with the USPTO. Not legal advice.** A provisional can be self-filed, but a registered patent practitioner should review claims scope and prior art before anything is disclosed publicly. Fees and form numbers below change — verify current values at [uspto.gov](http://uspto.gov) before filing.
## What a provisional actually does

- **Secures a priority date.** It establishes an effective filing date for whatever is *adequately described* in it, and lets you mark the subject matter “patent pending.”
- **It is never examined and never becomes a patent.** It is a placeholder.
- **It starts a hard 12-month clock.** You must file a corresponding **non-provisional** (or PCT) application claiming priority to it within 12 months, or the priority date is lost. This deadline is **not extendable**.
- **No claims are required**, but the disclosure must satisfy 35 U.S.C. §112 (written description + enablement) *for the subject matter you later want to claim*. Anything not supported in the provisional gets only the later non-provisional date. This is the single most common way provisionals fail — file a thin provisional, lose the early date on the parts that matter. Our draft is intentionally full-length for this reason.

## What you submit

| Item | Required? | Notes |
| --- | --- | --- |
| Specification (written description) | **Yes** | The body of [[ECSEQ/IP & Patents/Provisional Patent Application No. 1 — Draft]]. Claims optional but harmless to include. |
| Drawings | If needed to understand the invention | Figs. 1–7 are listed in the draft but not yet produced. Informal/hand drawings are accepted in a provisional. Include them — missing figures = unsupported disclosure. |
| **Provisional Cover Sheet (Form SB/16)** | **Yes** | Identifies the filing as provisional, lists inventors, title, correspondence address. Auto-generated in Patent Center. |
| **Application Data Sheet (ADS, Form AIA/14)** | Recommended | Cleanly records inventors, residence, applicant/assignee (Proprium Labs, Inc.). |
| Fee | **Yes** | See below. |
| Micro/Small Entity certification | If claiming reduced fees | Form SB/15A (micro) — see entity status below. |
| Assignment to Proprium Labs | Optional at filing | Can be recorded later via the Assignment Center; inventors should have signed assignment agreements regardless. |

## Fees (verify — changed Jan 2025)

The provisional filing fee is set by 37 CFR 1.16(d). Approximate current values:

| Entity status | Approx. provisional filing fee |
| --- | --- |
| Large entity | \~\$325 |
| **Small entity** (\<500 employees) | \~\$130 |
| **Micro entity** | \~\$65 |

**Proprium Labs almost certainly qualifies for micro entity** (small entity by headcount, gross income under the threshold, fewer than the application-count cap). Confirm against the current 37 CFR 1.29 criteria and file Form SB/15A. Micro vs. large is a \~5× fee difference, so it's worth confirming, but the absolute dollars are small — do not let fee-status uncertainty delay a filing near a disclosure deadline; you can pay the higher fee and correct later.

## Step-by-step (Patent Center)

1. **Get a** [**USPTO.gov**](http://USPTO.gov) **account** and verified access to **Patent Center** ([patentcenter.uspto.gov](http://patentcenter.uspto.gov)). Identity verification can take a few days — do this well before any deadline.
2. **Finalize the documents.** Convert the spec to a clean PDF (and a separate drawings PDF). Confirm every claim/feature you care about is actually described in the text.
3. **Confirm inventorship.** List all and only true inventors (contributors to the conception of a claimed feature). Getting this wrong is a substantive defect, not a formality.
4. **Start a new submission** in Patent Center → **Utility → Provisional**.
5. **Upload** the specification PDF and drawings PDF; complete the SB/16 cover sheet and ADS inline.
6. **Set entity status** (micro/small) and attach the certification form.
7. **Pay** the filing fee.
8. **Submit and save the receipt.** The acknowledgement receipt shows the **application number and official filing date** — that date is your priority date. Record both in this folder.

## After filing

- **Mark “patent pending”** on the relevant subject matter / materials.
- **Calendar the 12-month deadline immediately** — with a 2–3 month buffer reminder, because the non-provisional + formal claims take real time to prepare.
- **Treat the priority date as fixed only for what's disclosed.** New developments (e.g., the faradaic third axis once validated, or measured chip data) added after filing get the later date — consider a second provisional for significant new material before the non-provisional consolidates everything.
- **Keep developing in the open carefully.** A provisional permits disclosure, but public disclosure also starts foreign-rights clocks (most non-U.S. jurisdictions require absolute novelty *before* any disclosure). If international protection matters, talk to counsel before publishing.
