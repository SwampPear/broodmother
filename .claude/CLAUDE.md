# broodmother

`../CLAUDE.md` indexes the workspace, the commands, and what is off limits.

Before writing code, read `.agents/STYLE.md` — binding — and `.agents/LESSONS.md`. How work
gets done from a request to a verified change is `.agents/implement/`. Before reviewing
code, `.agents/REVIEW.md`.

## In-depth review

When I ask for a _thorough_, _deep_ or _in-depth_ review — as opposed to a quick look —
`.agents/REVIEW.md` is the floor rather than the whole job. Reading is not enough: run the
tests, the type checker and the app itself, report what you ran and what it printed, and
reproduce anything you claim is broken before you file it.
