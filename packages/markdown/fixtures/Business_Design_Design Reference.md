## Fonts
All fonts are open source and available via Google Fonts.

| Role               | Family         | Weights  | Usage                           |
| ------------------ | -------------- | -------- | ------------------------------- |
| `mono`             | Ubuntu Mono    | 400, 700 | Special body text, mono         |
| `sans`             | Funnel Sans    | 300–800  | Default body text               |
| `display/headings` | Funnel Display | 300–800  | Titles, headings, table headers |

## Colors

### Primary Pallete

These are our primary colors.

| Color | CSS Variable | Hex | Role |
| --- | --- | --- | --- |
| White | `--white` | `#fffeee` | Primary light |
| Black | `--black` | `#1f1f1f` | Primary dark |
| Dark | `--dark` | `#0f0f0f` | Secondary dark |

### Opalescent Palette

Iridescent accent colors meant to be used with each other in reference to the sheen of patterned silicon.

| Color | CSS Variable | Hex | Role |
| --- | --- | --- | --- |
| Opal violet | `--opal-violet` | `#c084fc` | Primary accent |
| Opal indigo | `--opal-indigo` | `#818cf8` | Borders, links |
| Opal cyan | `--opal-cyan` | `#22d3ee` | Borders, link hover |
| Opal mint | `--opal-mint` | `#34d399` | H4 borders |
| Opal gold | `--opal-gold` | `#fbbf24` | Gradient mid, highlight accent |
| Opal rose | `--opal-rose` | `#f472b6` | Gradient end |
