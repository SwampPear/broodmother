# Lessons

Things agents got wrong more than once. Every entry here exists because the same mistake
happened twice — this is not a style guide, and nothing goes in preemptively.

Applies to every agent working in this repo. A lesson that only holds for one package
belongs next to that package instead.

## When to add an entry

You corrected the same class of mistake in this repo before — same wrong assumption, same
wrong tool, same wrong shape of fix — and the correction wasn't obvious from the code or
the existing docs. If it happened once, fix it and move on. If a doc already covers it and
you missed it, the fix is a pointer from here to that doc, not a restatement.

## Format

One `##` section per lesson: what went wrong, why, and what to do instead. Keep it to a
few lines. Delete entries that stop being true — a stale lesson is worse than none.

```
## Short name for the mistake

**Wrong:** what was done.
**Why:** the reason it fails here.
**Instead:** the correct move.
```
